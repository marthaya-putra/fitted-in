**Scope:** full visual redesign of the Chrome side-panel extension (`apps/extension/`) through the `emil-design-eng` craft lens, with motion governed by the `find-animation-opportunities` gate (restraint-first). Deliver as a PR to `main`. Explicit request overrides the "DO NOT COMMIT" memory.

## Part A — Skill analysis (drives the work)

### emil-design-eng review (Before/After — current bugs)

| Before | After | Why |
| --- | --- | --- |
| `.btn-press { transition: transform 100ms ease-in … }` (`index.css:158`) | `transition: transform 120ms var(--ease-out)` | `ease-in` makes every press feel sluggish; UI must `ease-out` |
| `cubic-bezier(0.16,1,0.3,1)` hardcoded ~5× (tailwind.config, index.css, content.css) | `var(--ease-out)` token | One source of truth, no drift |
| `var(--space-1, 0.25rem)` referenced but **never defined** (`index.css:93`) | define `--space-1`…`--space-8` scale | Silent fallback bug |
| UserMenu popover `animate-slide-in` from translateY(8px), origin = center (`user-menu.tsx:29`) | scale from trigger via `transform-origin: var(--radix-popover-content-transform-origin)` | Popovers scale from their trigger |
| Floating banner hover ungated (`content.css:36`) | `@media (hover:hover) and (pointer:fine)` | Touch devices false-trigger hover on tap |
| No `prefers-reduced-motion` handling anywhere | gentle reduced-motion block (fade-only, no transforms) | A11y; motion sickness |
| Toasts/empty states use `scale`-less fades only | keep — already correct (never from `scale(0)`) | Good baseline |

## Part B — Design system & token changes

**`packages/ui/src/styles/globals.css`** — add to `:root`:
```css
/* Motion */
--ease-out: cubic-bezier(0.23, 1, 0.32, 1);
--ease-in-out: cubic-bezier(0.77, 0, 0.175, 1);
--ease-drawer: cubic-bezier(0.32, 0.72, 0, 1);
--ease-emphasized: cubic-bezier(0.16, 1, 0.3, 1);
--duration-fast: 120ms;  --duration-base: 200ms;  --duration-slow: 400ms;
/* Spacing (fixes undefined --space-1) */
--space-1:.25rem;--space-2:.5rem;--space-3:.75rem;--space-4:1rem;--space-5:1.25rem;--space-6:1.5rem;--space-8:2rem;
```
**`apps/extension/tailwind.config.js`** — refactor `animation`/`keyframes` to reference tokens via CSS-var timing where possible; keep `slideIn/Up/fadeIn/staggerIn` but standardize on `--ease-out`.

**`apps/extension/src/index.css`** — fix `.btn-press` easing; add `@media (prefers-reduced-motion: reduce)` (fade-only); add `@media (hover:hover) and (pointer:fine)` hover helpers; tighten the `.prose` hierarchy (defined spacing scale).

## Part C — Component redesigns (per screen)

Keep the proven 4-zone shell (header / scroll-content / action / footer) for the narrow panel. Elevate each surface:

1. **Shell `App.tsx`** — header: refined brand mark (primary/10→subtle gradient chip) + 2-line job title hierarchy + tiny "ready" status dot; action zone: stronger primary button with fixed press; footer: cleaner spacing.
2. **`login-form.tsx`** — refined card (softer shadow, better input affordance, consistent focus ring using `--ring`), keep existing layout.
3. **`loading-screen.tsx`** — faster spinner (perceived perf), refined mark; keep centered.
4. **`empty-state.tsx`** — `EmptyState` + `EmptyNoJob`: clearer hierarchy, primary-tinted icon chip (not flat muted), better caption rhythm.
5. **`progress-stepper.tsx`** — add vertical connector line that fills as steps complete; smooth pending→active→done badge morph; keep stagger.
6. **`resume-preview.tsx`** — refined sticky action bar (consistent radius/border with rest); Copy→Check crossfade (#5).
7. **`error-alert.tsx`** — refined destructive surface; `@starting-style` enter (#4).
8. **`user-menu.tsx`** — origin-aware popover (#2); refined avatar/trigger.
9. **`content.tsx` / `content.css`** — floating banner: touch-gated hover, refined shadow ramp, keep one-shot entrance (#6).

All animations stay CSS (transitions over keyframes for interruptible UI), animate `transform`+`opacity` only.
